# GapZero

**Find your gaps. Master every concept.**

GapZero is a free, local-first learning platform for school and competitive-exam students. Its planned core modules are Gap Finder, ReviseOS, Practice, and Progress Analytics.

## Product principles
- ₹0 core experience; no paid APIs or required subscriptions
- No login in V1
- Local-first student data with JSON backup and restore
- Smart Mode fallback when optional on-device AI is unavailable
- Mobile-first, accessible, and responsive

## Status
Repository initialized. Product implementation and quality assurance are the next steps. This README does not claim that planned features are already implemented.
